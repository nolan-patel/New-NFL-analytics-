# NFL Analytics Dashboard

A Streamlit NFL analytics portfolio project using nflverse data.

## Features
- 2023, 2024, 2025 seasons
- Offense and defense EPA/play
- Success rate
- EPA/pass and EPA/rush
- Team filtering
- Offense vs defense scatterplot
- QB, RB, WR, TE player leaderboards
- Multi-season team trends

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Upload these files to a GitHub repo, then deploy `app.py` through Streamlit Community Cloud.
